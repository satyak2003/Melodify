# Changelog - Melodify v0.1.3-beta

- **UI Enhancements**: Added an Equalizer settings screen for Android and Desktop.
- **Audio Output Manager**: Output device picker added.
- **Equalizer Engine**: Integrated VLCJ and ExoPlayer for actual 10-band audio equalization.
- **Desktop UI**: Added screen transition animations, sliding sidebar highlight, and icon click animations.
- **Sidebar**: Fixed animated visibility text wrapping bugs in the sidebar.
- **Home Screen**: Refactored home screen widgets to be horizontally scrollable to prevent text cutoff on narrow devices.
- **MiniPlayer Layouts**: Enhanced responsive mini-player layout and interactions.
